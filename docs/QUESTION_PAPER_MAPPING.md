## 3. Source Document Observations & Examination Notes

1. **Subject Paper Q2 (`Break` vs. keywords):**
   - The docx provides `Break` (capital B), `def`, `with`, and `global`.
   - In Python, `break`, `def`, `with`, and `global` are lowercase reserved keywords. Because Python is strictly case-sensitive, `Break` is syntactically a valid user identifier. The correct option is verified as **Option A**.
2. **Subject Paper Q5 (`None` vs. `none`):**
   - The source document provides both `The function will return None.` (Option C) and `The function will return none.` (Option D).
   - In Python, the singleton object is spelled with a capital N (`None`). The correct option is verified as **Option C**.
3. **Subject Paper Q8 (`Li` vs. `li` casing):**
   - In the docx snippet, line 1 is `Li = [...]` and line 2 is `print(li[1][-1])`.
   - In interactive Python, this raises `NameError` if `li` is undefined. In standardized school assessments, this represents a typographical variance from word-processing auto-capitalization, where the conceptual intent tests nested list indexing: `list[1] == 'Emma'`, and `'Emma'[-1] == 'a'`.
   - The correct answer is confirmed as **Option B (`a`)**.
